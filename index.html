🏠 There is / There are Spotlight 6

Rooms & Furniture · a / an / some / any

✨ There is / There are

🟢 AFFIRMATIVE (утвердительная)

There is + a / an + singular noun
There are + some + plural noun

There is a sofa in the living room.

There are some cushions in the living room.

🔴 NEGATIVE (отрицательная)

There isn't + a / an + singular noun
There aren't + any + plural noun

There isn't a chair in the living room.

There aren't any chairs in the living room.

🔵 QUESTIONS (вопросительная)

Is there + a / an ...? — Yes, there is. / No, there isn't.
Are there + any ...? — Yes, there are. / No, there aren't.

Is there a book in the living room?

Are there any books in the living room?

🔑 a / an / some / any

a — перед согласной: a sofa, a table, a lamp

an — перед гласной: an armchair, an orange, an old picture

some — в утвердительных (мн. ч.): some cushions, some paintings

any — в отрицательных и вопросах: any chairs, any books

⚡ Tip: There is = единственное число. There are = множественное. Всегда смотри на существительное после конструкции!
